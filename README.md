# 📚 גאווה מול התנשאות — **PrideRise (PR)**

### 🔥 מפת עומק מתוך *ספר המידות* לרבי נחמן מברסלב זיע״א

**📅 יום שישי, י׳ באב ה׳תשפ״ו — 24 ביולי 2026 | 🕐 01:17, שעון ישראל**. התאריך העברי מאומת כלוח י׳ באב תשפ״ו. ([חבד][1])

מצאתי ואימתתי שאכן התכוונת ל־**מידת התנשאות**. בספר עצמו קיימים שני ערכים נפרדים: **״גאוה״** ו־**״התנשאות״**. ([ויקיטקסט][2])

והממצא המרכזי חד מאוד:

> **גאווה = האדם מרים את עצמו.**
> **התנשאות = האדם מורם למעמד, שליחות, הנהגה או חשיבות.**

כלומר: **לא כל התנשאות היא גאווה.** להפך — בספר המידות יש התנשאות שבאה דווקא מתוך **שפלות, הכנעה, צדקה, אמונה, רחמנות, לימוד תורה וקידוש השם**. ([ויקיטקסט][3])

## 🔎 1. מה מצאתי בסריקה

### 🔥 מידת גאווה

בערך **גאווה, חלק א׳**, מופיעים **40 סעיפים — א׳ עד מ׳**. רובם מתארים את הגאווה כמצב שדורש שבירה ותיקון: היא קשורה לנפילה באמונה, סגירת הלב, פחד, כעס, שכחה, כישלון המחשבה, פגיעה בתפילה ובחכמה ועוד; לצד עצות כגון צדקה, השתתפות בצרת ישראל, אמונה והתבוננות בשמים. ([breslev.eip.co.il][4])

### 👑 מידת התנשאות

בערך **התנשאות** יש **45 סעיפים בחלק הראשון ועוד 12 בחלק השני — 57 בסך הכול**. כאן התמונה שונה: מדובר הרבה על גדולה, הנהגה, פרסום, שררה, נשיאות ועלייה — כיצד זוכים להם, כיצד הם מתקיימים, מתי הם מן השמים ומתי נטילת השררה היא פסולה. ([ויקיטקסט][3])

# 🧠 3. ארבעים פרשנויות והבחנות עומק

## 🔥 שער א׳ — מי מרים את מי?

### 1️⃣ גאווה אומרת: **״אני גדול״**

התנשאות ראויה אומרת: **״הוטלה עליי גדולה״**.

זו אחת ההבחנות העמוקות ביותר. בגאווה האדם הוא המקור לכבודו; בהתנשאות תקינה הגדולה נתפסת כפיקדון.

### 2️⃣ בגאווה האדם **לוקח גובה**

בהתנשאות האדם **מקבל גובה**.

### 3️⃣ גאווה היא זהות

״אני מעל האחרים״.

התנשאות היא תפקיד:
״עליי לעמוד במקום גבוה כדי לבצע שליחות״.

### 4️⃣ הגאה רוצה את הכיסא

המתנשא כראוי צריך להיות ראוי לכיסא.

בספר מופיעה בדיקה ב״דבר קטן״ לפני נתינת גדולה. ([ויקיטקסט][3])

### 5️⃣ גאווה נאחזת בגדולה

התנשאות כשרה מוכנה גם להעביר אותה לאחר.

רבי נחמן מציין שלא בכל עת אדם יכול להנהיג את נשיאותו, ולעתים השעה זקוקה לנשיא אחר. ([ויקיטקסט][3])
